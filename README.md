# ShadowTrial

ShadowTrial is a 3D platformer prototype created in Unity as part of a university assignment.

The project focuses on basic platforming mechanics such as movement, jumping, falling, and checkpoint-based respawning.

## 🎮 Demo

![Demo](/media/demo_short.gif)

## 🚀 Features

- Third-person character movement
- Jumping and falling mechanics
- Death system (falling off the map increases death counter)
- Checkpoint system (respawn after falling)
- Basic animated character
- Camera rotation around the player

## 🛠️ Tech Stack

- Unity
- C#

## 📌 Notes

- This is an early prototype
- The level currently consists of simple placeholder geometry (basic cubes)
- More features and improvements will be added in the near future
